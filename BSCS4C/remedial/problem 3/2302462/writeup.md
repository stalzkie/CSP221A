The reason why the averages/flags count as "vectorized" is because Numpy is the one who performs the operations, such as for the averages it is self.times.mean(axis=1) that performs getting the averages across the rows and for the flags it is np.where() which labels the time if the lap time was SLOW or FAST.  It is vectorized because we use Numpy to operate with the rows rather than manually performing the calculations. When it is vectorized, it is more efficient than using loops to perform the calculations.
