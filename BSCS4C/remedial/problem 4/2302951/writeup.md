I used a generator function called clean_tickets to loop through the raw ticket data. Inside the loop, parse_ticket_line is placed in a try...except block so if a ticket is broken, it raises TicketFormatError. Instead of crashing the whole program, clean_tickets just prints why that line was skipped and keeps going with the next valid ticket. Creating a custom TicketFormatError helps make it really clear that error was caused by bad ticket formatting instead of some other bug in the code.
