#I use a generator for the clean_tickets function because it can give the valid tickets one at a time using yield. It does not need to make all the result first before giving the tickets. For me this is useful when there is many data to process. A malformed line is when the ticket does not have exactly three parts, or when the priority is not low, medium, or high. The program will skip this bad lines so the other valid ticket can still be processed.
