First thing i did to meet the requirements was to structure the build_catalog to go through the raw rows one at a time. For each row, it calls the Book.from_dict, wherein it creates a Book and then runs the year and copies the inteded property setters too. Now, if both values pass validation then the book is added to the books list. Also, if either setter raises a CatalogError, the function catches that error and adds the original row and its error message to the failures list. I as well count a row as a failure when it has an invalid publication year or an invalid number of copies. Zero copies is valid, even though that book cannot be checked out. Lastly, the function returns both lists so valid books can still be ranked even when some rows fail.
