The average_cycle_time() and flag_long_cycles() count as vectorized because .mean(axis=1) and np.where() do the match across all robots all at once, instead of checking each one seperately. NumPy handles the looping internally, much faster than plain Python. If we weren't careful and used a regular for loop to go through each robot one by one, or if/else statements to check values individually, we would lose that speed benefir and would end up doing the same work but in amuch slower way.
