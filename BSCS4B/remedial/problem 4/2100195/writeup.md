I used a generator for clean_signups because it was instructed to use yield, and honestly it makes more sense to me than building up a whole list first. If one line is bad, the generator just skips it and moves on, we can somewhat say that the rest of the program doesn't even know something went wrong. I think for a small dataset like this it doesn't really matter when it comes to performance, but if we had way more lines it would save memory since we're only holding one record at a time. 

For "malformed" lines, I was able to check two things, does the line split into exactly 3 parts on "|" and is the shift actually one of morning/afternoon/evening. V006 fails the first check because it only has 2 fields, and V004 fails the second check because "night" isn't valid. Both raise my custom SignupFormatError so the generator can catch them and print a message instead of just crashing.
